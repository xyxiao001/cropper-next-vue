# 文档体验契约

## 路由

以下路径直接保留：

`/`、`/guide`、`/props`、`/methods`、`/changelog`、`/event`、`/scenario-avatar`、`/scenario-cover`、`/scenario-product`、`/demo-basic`、`/demo-loading`、`/demo-drag`、`/demo-crop`、`/demo-img`、`/demo-filter`、`/demo-rotate`、`/demo-realtime`、`/demo-export`、`/demo-all`、`/demo-geometry`。

新增 `/concepts` 承载概念讲解。保留 hash 路由，章节链接由 router path/hash 组合；不新增重定向或缺页兜底。

## 导航和语言

- 首页、快速开始、工作台可从主导航到达。
- 场景、功能示例、参考文档均有明确分组，不删除旧页面入口。
- 语言切换保持当前 path/hash，所有公共操作标签覆盖中文/英文。
- 目录、章节 ID 和学习顺序来自明确元数据，禁止按翻译文本猜测 ID。

## 内容和示例

- 所有复制示例提供公开组件和样式引入、图片输入说明和必要依赖。
- 首次裁剪导出不要求用户提供服务端接口；上传作为独立扩展示例说明。
- 30 props、16 methods、5 事件名与 loading/drag 插槽均可查阅。
- 明确 `centerWrapper` 的覆盖语义、示例配置与默认值差异、导出质量和尺寸区别。
- 主运行演示保留原有图片来源、请求时机、异常处理及事件行为。

## 视觉和交互

- 首页以实际裁剪图像和结果为主，文档以阅读为主，工作台以编辑空间为主。
- 375/768/1440px 下正文不被裁切，代码与表格只在局部滚动。
- 公共站点导航、目录、代码按钮支持键盘与可见焦点；不扩展裁剪组件键盘能力。
- 工作台编辑、导出、方法、数据四类能力完整保留，视觉稿的简化不代表删除功能。

## 不变契约

`lib/`、包版本、API、默认值、几何算法、事件时机、导出规则及错误处理保持原样。不新增校验、拦截、重试、静默放行、备用素材或降级分支。
