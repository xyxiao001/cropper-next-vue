# 验证指南：裁剪状态与交互控制

## 准备

```bash
pnpm install
pnpm run dev
```

打开首页并选择一张图片。

## 场景 1：重置

1. 移动、缩放并旋转图片。
2. 调整裁剪框位置或大小。
3. 点击首页重置按钮。
4. 确认图片和裁剪框恢复初始状态，且没有出现图片重新加载过程。

## 场景 2：结构化状态

1. 监听 `change`。
2. 依次移动、缩放、旋转、调整裁剪框并重置。
3. 确认每次回调均符合 [公开 API 合同](./contracts/vue-cropper-api.md)。
4. 单独执行导出，确认没有新增 `change` 回调。

## 场景 3：交互开关

1. 关闭移动开关，确认图片和裁剪框不能拖拽，但公开方法仍有效。
2. 关闭缩放开关，确认滚轮和双指不能缩放，但首页缩放按钮仍有效。
3. 重新打开开关，确认下一次交互立即恢复。

## 自动检查

```bash
pnpm run check
pnpm run build:docs
```

预期：类型检查、覆盖率测试、库构建和文档站构建全部通过。
