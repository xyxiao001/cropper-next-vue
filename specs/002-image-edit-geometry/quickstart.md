# 快速验证：图片编辑与原图几何

## 前置条件

```bash
pnpm install
pnpm run dev
```

打开 `http://localhost:5173/#/demo-all` 并加载一张图片。

## 场景 1：缩放上下限

1. 设置可观察的最小和最大比例。
2. 连续使用滚轮、双指缩放以及公开缩放按钮越过两端。
3. 验证比例停在有效范围，达到边界后图片位置不继续变化。
4. 开启 `centerBox` 并配置低于覆盖要求的最大比例，验证最终比例固定在覆盖所需比例。

## 场景 2：水平与垂直翻转

1. 点击水平翻转，验证主视图、裁剪框预览和状态中的 `flipX` 同步变化。
2. 在旋转 90° 后再次水平翻转，验证仍表现为屏幕左右镜像。
3. 点击垂直翻转并导出 base64/Blob，验证导出方向与预览一致。
4. 再次执行同方向翻转，验证恢复原方向；调用重置，验证两个翻转字段均为 `false`。

## 场景 3：原图裁剪坐标

1. 记录未变换状态下四角点与外接矩形。
2. 移动、缩放、设置任意旋转角并组合两个翻转。
3. 调用 `getCropCoordinates()`，验证四点顺序、源图尺寸和变换字段。
4. 对四点执行对应正向变换，应在 `0.01` 像素误差内回到裁剪框四角。
5. 记录调用前后的 `change` 数量，验证读取没有新增事件。
