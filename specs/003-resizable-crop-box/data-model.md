# 数据模型：可缩放裁剪框

## 1. 裁剪框几何状态

表示裁剪框在容器坐标系中的可见范围。

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `x` | number | 左边界到容器左侧的距离 | `0 <= x <= wrapper.width - width` |
| `y` | number | 上边界到容器顶部的距离 | `0 <= y <= wrapper.height - height` |
| `width` | number | 裁剪框宽度 | 正数，且 `x + width <= wrapper.width` |
| `height` | number | 裁剪框高度 | 正数，且 `y + height <= wrapper.height` |

该状态继续映射到现有 `change.crop`、实时预览、导出参数和原图裁剪坐标。

## 2. 缩放方向

一次会话只能有一个方向：

- `n`：上边
- `s`：下边
- `w`：左边
- `e`：右边
- `nw`：左上角
- `ne`：右上角
- `sw`：左下角
- `se`：右下角

方向决定当前指针可以改变哪些边界；未被选中的对边保持起始位置。

## 3. 缩放会话

| 字段 | 类型 | 含义 |
|---|---|---|
| `direction` | 缩放方向 | 当前控制点方向 |
| `startPointer` | `{ x, y }` | 会话开始时的容器坐标 |
| `startCrop` | 裁剪框几何状态 | 会话开始时的完整快照 |
| `active` | boolean | 会话是否正在接收移动输入 |

### 状态转换

```text
空闲
  └─ 按下控制点 → 缩放中（记录起始快照，取消待执行回弹）
       ├─ 指针移动 → 计算并提交新裁剪框几何
       └─ 松开/触摸结束 → 空闲（清理监听，执行一次图片回弹）
```

### 几何规则

- 拖动左边或上边时，对应 `x/y` 和 `width/height` 同时变化。
- 拖动右边或下边时，只改变 `width/height`。
- 拖动角时组合对应的横向和纵向规则。
- 每个方向均受容器边界和内部 `24px` 最小交互尺寸限制。
- 单次提交必须同时包含位置和尺寸，不能暴露中间不一致状态。

## 4. 裁剪辅助视觉状态

该状态由现有公开参数和裁剪框可见状态派生，不独立保存：

| 条件 | 九宫格 | 八方向控制区 |
|---|---|---|
| `cropBoxResizable = true`、裁剪框可见且正在缩放 | 显示 | 显示 |
| `cropBoxResizable = true`、裁剪框可见且缩放结束 | 约 400ms 渐隐后隐藏 | 显示 |
| `cropBoxResizable = false` | 隐藏 | 隐藏 |
| 图片未加载或全屏裁剪模式 | 隐藏 | 隐藏 |

九宫格只提供构图参考，不参与命中、几何计算、状态事件或导出结果。
